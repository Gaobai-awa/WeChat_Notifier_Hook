# WeChat_Notifier_Hook
基于[Wechat_hook](https://github.com/aixed/WeChat-Hook)与微信[4.1.10.27](https://github.com/Rodert/wechat-win-versions/releases/download/v4.1.10.27/WeChatSetup-4.1.10.27.exe)制作出的让微信接受通知时使用原生windows通知功能发布通知

## 环境要求
### 必要
- Windows 8/10/11
- [Wechat 4.1.10.27](https://github.com/Rodert/wechat-win-versions/releases/download/v4.1.10.27/WeChatSetup-4.1.10.27.exe)(安装[Wechat_hook](https://github.com/aixed/WeChat-Hook))
### 选择
- 你需要监听的人的wxid_开头原始微信号(当然你可以选择监听所有人的消息，不需要微信号)
